# Proyecto_RappiPlus_de_datos_a_decisiones_negocio
##📊 RappiPlus Business & Customer Analytics: Rentabilidad, Retención y Conversión 

📌 Descripción del Proyecto
Análisis integral del desempeño de RappiPlus, servicio de suscripción del ecosistema Rappi, para evaluar rentabilidad, comportamiento de usuarios, retención y eficiencia del proceso de compra. El proyecto integró análisis de calidad de datos, KPIs financieros, funnels de conversión, cohortes de retención, experimentación A/B y visualización ejecutiva para generar recomendaciones orientadas al crecimiento y la optimización del negocio.

🎯 Objetivos
Validar la calidad y confiabilidad de los datos.
Analizar la rentabilidad del modelo de suscripción.
Identificar puntos críticos de abandono en el proceso de compra.
Evaluar la retención y recurrencia de usuarios.
Medir el impacto de cambios implementados mediante pruebas A/B.
Comunicar hallazgos mediante dashboards ejecutivos orientados a negocio.

🔍 Metodología
1. Preparación y Calidad de Datos
Limpieza y validación de datasets.
Identificación de valores faltantes, inconsistencias y duplicados.
Estandarización de variables para análisis posterior.
2. Análisis de Rentabilidad
Cálculo de KPIs financieros:
Revenue
Cost
Profit
Margen de contribución
Identificación de segmentos y categorías más rentables.
3. Funnel de Conversión
Construcción del recorrido completo del usuario.
Medición de conversión por etapa.
Detección de puntos de abandono (drop-off).
4. Análisis de Cohortes
Segmentación de usuarios por fecha de registro.
Evaluación de retención y recurrencia.
Comparación de comportamiento entre cohortes.
5. Experimentación A/B
Comparación entre grupo control y tratamiento.
Validación estadística de diferencias en conversión.
Evaluación del impacto de cambios en producto.
6. Dashboard Ejecutivo
Consolidación de indicadores clave.
Visualización de tendencias, cohortes y funnel.
Comunicación de insights para stakeholders.

📈 Principales Resultados
✅ Identificación de categorías y segmentos con mayor rentabilidad.
✅ Detección de etapas críticas con mayor abandono dentro del funnel de compra.
✅ Análisis de cohortes para comprender patrones de retención y recurrencia.
✅ Evaluación estadística de cambios en producto mediante pruebas A/B.
✅ Desarrollo de dashboard ejecutivo para monitoreo de KPIs comerciales y de comportamiento de usuarios.

💡 Insights de Negocio
Los usuarios con mayor recurrencia concentraron una parte significativa del valor generado.
Se identificaron oportunidades de mejora en etapas específicas del funnel para reducir abandono.
El análisis de cohortes permitió detectar diferencias de retención entre segmentos de usuarios.
La experimentación A/B proporcionó evidencia para respaldar decisiones de producto basadas en datos.
